# Portfolio de Samuel Yoka

Portfolio personnel de Samuel Yoka, étudiant en informatique et développeur web à Brazzaville. Le site présente mon parcours, quelques projets et les moyens de me contacter.

**Voir le portfolio :** [samuelakombo0-bit.github.io/Portofolio](https://samuelakombo0-bit.github.io/Portofolio/)

## Aperçu

- Présentation personnelle et sélection de projets
- Mise en page responsive pour ordinateur, tablette et mobile
- Thème clair/sombre, avec préférence mémorisée dans le navigateur
- Menu mobile accessible au clavier
- Animations d’apparition respectant la préférence de réduction des animations
- Formulaire de contact et liens vers mes profils
- CV téléchargeable depuis le site

## Technologies

- HTML
- CSS
- JavaScript natif

Le site est actuellement statique : aucun outil de compilation ni installation de dépendances n’est nécessaire pour le consulter.

## Lancer le site en local

1. Clonez le dépôt :

   ```bash
   git clone https://github.com/samuelakombo0-bit/Portofolio.git
   cd Portofolio
   ```

2. Ouvrez `index.html` dans votre navigateur.

Vous pouvez aussi lancer un serveur web local depuis le dossier du projet, puis ouvrir l’adresse indiquée par ce serveur.

## Structure du projet

```text
Portofolio/

├── index.html    # Structure et contenu de la page
├── script.js     # Thème, menu mobile et animations
```
